## 📖 简介

作者为清华大学 **2022 级电气工程及其自动化专业（能源互联网国际班）** 本科生。  
本项目记录了作者在清华电机系就读本科期间的课程资料，希望能对未来的电机学子们提供一定帮助！  
*(注：虽然自 2025 年起电机系不再直接招收本科生，名额均分配至各书院。)*

> [!NOTE]
> **阅读前注意**
> - **选课节奏**：作者并非卷王，修读的课程及学期选课安排**较为养生**。若你想在电机系度过一个**比较舒服**的本科生活，可参考本项目的学期安排进行选课。
> - **课程差异**：作者为港澳台学生，仅需修读**思想道德与法治**一门思政课；同时在**微积分 A(1)**、<br>**微积分 A(2)**、<br>**线性代数**、<br>**大学物理 B(1)**、<br>**大学物理 B(2)** 等数理基础课程上皆选择了“国际班”（专门为港澳台及国际学生开设的平行班，与英文班有别）。因此本项目在思政课及上述数理基础课中无法提供全面帮助。

## ⚖️ 国际班培养方案的差异

> [!IMPORTANT]
> 国际班无需修读 **高等电路分析**！

| 培养项目 | 普通班 | 国际班 |
| :--- | :--- | :--- |
|   **总学分**   | 157 学分 | 161 学分 |
| **学科交叉课** | 能量转化原理与技术、<br>大数据技术与应用、<br>能源互联网导论（**三选一**） | 热力学与传热学基础、<br>大数据技术与应用、<br>能源互联网导论（**三门皆为必修**） |
| **专业选修课** | 各课组共不少于 7 学分 | A+B 不少于 7 学分<br>（A 组不少于 4 学分，B 组不少于 2 学分） |
| **英文核心课** | 至少选 2 门 | 至少选 4 门 |
